## 2025-05-18 - Missing Focus and Interaction States on Custom Buttons
**Learning:** When building custom button classes with CSS without using an existing UI component library, it's very common to forget to explicitly specify focus (`:focus-visible`), hover (`:hover`), and active (`:active`) states. This severely degrades accessibility, particularly for keyboard users, who rely on `focus-visible` to know where they are on the page.
**Action:** When working on generic button CSS or reviewing custom UI elements, check if there's a visible focus indicator and hover/active visual feedback. Ensure `outline` combined with `outline-offset` is used to provide strong visual contrast for focus indicators instead of relying just on background color changes which might fail contrast rules.
